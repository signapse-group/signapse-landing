## Goal

Create, select, and rename a workspace; add or remove watchlist assets, then check that the list was saved to the intended workspace.

A workspace is your personal tracking space. Its watchlist contains the assets you want to follow. News, events, and market knowledge are shared; adding an asset to a watchlist does not create a private copy of that data.

## Prerequisites and permissions

You have been granted access to Signapse. Selecting, creating, and renaming workspaces require the relevant permissions. Managing a watchlist requires permission to read assets, read the tracked asset list, and add and remove assets. See [Account, permissions and limits](/en/docs/ug02).

Before editing the list, check the active workspace and the assets you want to keep. Limits may block workspace creation or saving your asset selection; read the on-screen message and your account's **Usage limits** values.

## Steps

### 1. Select the workspace to use

Open the workspace selector at the top of the app. Select the workspace name and wait for the action to finish. Check the name displayed in the selector; the current workspace has a check mark and an **Active** status in the list.

Before switching workspaces, save or discard any watchlist edits in progress. After switching, check the workspace name again before continuing.

### 2. Create a workspace

In the selector menu, select **Create workspace**. Enter a recognizable name, such as “Market tracking”, then select **Create workspace** to confirm. The name must not be blank.

After the success message, reopen the selector and check for the new workspace. Select it if it is not already active.

### 3. Rename a workspace

Select the workspace you want to rename. Open the selector menu, select **Rename workspace**, edit the name, and select **Save changes**. Check the update message and the new name in the selector.

### 4. Add or remove assets

In the workspace selector menu, select **Manage tracked assets**. Read the workspace name in the dialog description and wait for the current list to load.

To add an asset, search by name or symbol. Check the name, symbol, and asset type in the results, then select the appropriate item. Selected symbols appear in the selection area.

To remove an asset, select the **×** button beside its selected symbol. Keep the symbols you still want to follow. Removing an asset here changes the workspace watchlist; it does not delete the asset or news from the shared data store.

### 5. Save and check the list

Review the entire selection and the selected asset count, then select **Save list**. Wait for a successful update message. Reopen **Manage tracked assets** in the same workspace to check the assets added, removed, and retained.

If the interface reports **There are no changes to save**, your selection matches the loaded list. If an error appears, follow the troubleshooting section below before saving again.

### 6. Close with unsaved changes

When you select **Cancel** or close the dialog with unsaved changes, the interface asks **Discard unsaved changes?**. Select **Continue editing** to return to the list, or **Discard changes** to close it and discard unsaved edits.

Discarding unsaved edits does not undo changes that were already saved successfully.

## Expected result

The active workspace name matches the space you intend to use. When you reopen asset management, the saved list contains the assets you want to follow in that workspace.

The watchlist helps set the scope of your personal experience; news, evidence, and chart availability for each asset still depend on the available data. Continue with [Reading the Overview](/en/docs/ug04).

## Troubleshooting

| Symptom                                                          | Next action                                                                                                                                                                                                                             |
| ---------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Creating, renaming, or managing assets is missing or unavailable | Check the selected workspace and relevant permissions using [Account, permissions and limits](/en/docs/ug02). Contact the person who granted access if you remain blocked.                                                              |
| The workspace name is rejected                                   | Enter a nonblank name and follow the message shown when creating or renaming.                                                                                                                                                           |
| An asset cannot be found                                         | Check the name or symbol you entered and the search results. If searching fails, use the retry action shown; do not select a different asset merely because its symbol looks similar.                                                   |
| The current list fails to load                                   | Select **Retry** and wait for loading to finish. Do not treat a loading error as an empty list or replace the list before you can read its current state.                                                                               |
| A limit is exceeded                                              | Check the limit and current usage. Adjust the selection to your needs; only remove assets you deliberately want to stop following. If you remain blocked or the values do not match the message, contact the person who granted access. |
| Saving fails or only some changes are saved                      | Wait for the current list to reload. Compare it with the list you want, reapply the remaining changes, and save again. If reloading also fails, resolve the loading error first. Do not assume the whole operation was rolled back.     |

If you cannot resolve the issue, note the workspace, action, message, and time of occurrence. Contact the person who granted access so they can receive the issue and refer it to the appropriate person if needed. See [Missing data or features](/en/docs/ug08).
