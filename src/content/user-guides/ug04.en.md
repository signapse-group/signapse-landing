## Goal

Identify the workspace in use, read the information areas on the Overview, and choose an event or article to check further. Distinguish time, data scope, permission restrictions, empty states, and errors before interpreting the information.

## Before you start

Select an active workspace before reading the Overview. Your permissions determine which data sections you can see.

To follow assets you care about, check the workspace watchlist first. Do not assume every asset already has news, events, or evidence.

## Steps

### 1. Open the Overview and check the workspace

Select **Overview** in the app navigation. Compare the workspace name on the page with the workspace selector at the top of the app.

Under **Tracked assets**, read the names, symbols, and types in the selected workspace's full watchlist. To check or change the list, select **Manage tracked assets**. See [Workspaces and watchlists](/en/docs/ug03).

### 2. Read the information areas

| Area | How to read it |
| --- | --- |
| Summary cards | Read **Next key event**, **Market events**, **Market narratives**, and **Latest news** together with the description under each value. Metrics have their own time windows or status conditions; do not compare them as if they represented the same dataset. |
| **Event timeline** | Read the title, description, themes, affected assets, occurrence time, and confidence when available. Shows the first five eligible events for the watchlist, in the order supplied by the system. |
| **Latest news** | Read the title, short description, news source, and publication time. Shows up to five latest articles across Signapse; the count card covers articles published in the last six hours. |
| **Assets in focus** | Read the asset name, symbol, type, accompanying context, and observation time. A prominent position is a starting point for investigation, not a buy or sell instruction. Select **Open Market Charts** for further exploration using [Reading market charts](/en/docs/ug06). |
| **Market narratives** | Read the title, interpretation, status, theme, related assets, confidence, and update time when available. The list shows up to three ranked narratives from the last seven days in this workspace. The summary card counts all active or emerging narratives, with no seven-day limit. A narrative is a market interpretation whose supporting evidence needs checking, not a certain conclusion. |

### 3. Distinguish times and data states

Read each area’s time label; the workspace modification time is not the update time for all market data.

For example, Market events counts the last 24 hours, while Event timeline can include events older than 24 hours. These counts may differ.

Wait for loading to finish. Distinguish **0** from **No data**, **Unavailable** accompanied by a permission description, and **Could not load**. Read each area's own message; one area's error or empty state does not establish the same state for the rest of the page.

### 4. Open an event or article to check it

In **Event timeline**, select a title to open its detail panel. Read the description, occurrence time, related assets, and **Main evidence** when available. From an evidence item, use **View article** or **Open original** when a link is available to compare the external source.

In **Latest news**, select a title to open the article detail panel. Check the source, publication time, and content; use the original link when available to check the source article.

When needed, use the full-page action in the detail panel, or close the panel to return to the Overview. **View all events** and **View all news**, when displayed, lead to their respective lists; check the scope and filters on the destination page. See [Reading news, events and evidence](/en/docs/ug05) for detailed source checking.

## Expected result

You can identify each area’s scope and open an event or article to read further.

## Troubleshooting

- **No workspace or the wrong tracked asset list:** select the intended workspace and check its watchlist using [Workspaces and watchlists](/en/docs/ug03).
- **An area is hidden or reports missing permissions:** Read the on-screen message and see [Missing data or features](/en/docs/ug08).
- **Data is empty, a time is missing, or loading fails:** read the affected area's message and follow [Missing data or features](/en/docs/ug08). Do not interpret empty data as the absence of market events.
- **Details will not open or the source article is missing:** note what you could not check. Use **Retry** when available; if the issue persists, see [Missing data or features](/en/docs/ug08).
