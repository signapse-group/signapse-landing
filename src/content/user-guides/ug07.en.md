## Goal

Ask a clearly scoped market question, read the answer with its provided support and limitations, and follow up or reopen a conversation. Recognize when an answer lacks enough data to verify it, and handle errors or exhausted AI turns.

## Before you start

You need access to the AI Assistant. Select an active workspace and check its tracked assets before starting.

Check **Usage limits** for remaining AI turns when needed.

An asset you want to analyze must be in the workspace's current watchlist. If it is absent or has been removed, add it and check the saved list using [Workspaces and watchlists](/en/docs/ug03) before requesting analysis. Naming an asset in a question or an old conversation does not expand the permitted scope.

## Steps

### 1. Open the AI Assistant and frame your question

Select **Ask Signapse** in the lower corner of the app. If the interface reports no active workspace, select a workspace first, then reopen the assistant.

In **Message**, state the asset, time range, and what you want to understand. Focus on one specific question; use explicit dates when you need to compare the answer later.

For example, replace the asset and dates below with your intended scope:

> For BTC in this workspace's watchlist, which events were notable from October 20 to 22, 2026? Identify supporting sources and missing data, and distinguish source statements from interpretation.

This illustrates how to frame a question; it does not establish that BTC or that period has data in your account. Specify only the asset you actually want to analyze.

### 2. Send and wait for a response

Select **Send**, or press **Enter**; use **Shift + Enter** for a new line. Your first question starts a new conversation with a title derived from the question.

Wait for sending, thinking, and responding states to finish before reading the full result or sending a follow-up. Use **Expand conversation window** when you need more reading space. Seeing some text appear does not establish that the response is complete.

### 3. Read the answer and check its support

Compare the answer with the preceding question: which asset and period does it discuss, and does it address what you asked? Distinguish source statements, interpretation, and uncertainty.

If links or identifiable events or articles are provided, open the sources and compare their titles, times, and content using [Reading news, events and evidence](/en/docs/ug05). A source name or general description alone is not verified support.

Check any stated data gaps or limitations. Confidence is not the probability of a price rise or fall; if sources are missing, ask for them before relying on a claim.

### 4. Follow up or start another topic

In the same conversation, identify what needs clarification, such as “Which source supports the second claim?” or “Which parts are observations and which are inferences?”. If support is missing, ask what data is unavailable rather than continuing to treat the claim as a fact.

If a follow-up concerns an asset removed from the watchlist, add it again before requesting analysis. Saved conversation content remains unchanged.

To change topics, select **New chat**. Keep a copy of any unsent draft before changing conversations or workspaces; starting a new conversation clears the current composer.

### 5. Reopen a conversation

If the app version you are using supports conversation history and your current workspace has saved conversations, you can find and reopen one as follows.

Open **Conversation history** in the window header. Search using words in the title, select the appropriate conversation, and wait for its messages to load. To read earlier content, select **Load older messages** when shown.

Check the workspace, title, questions, and message times before following up. Old content is a response from the previous exchange; reopening a conversation does not update its conclusions to current market conditions. State the time and information you want to check when you need a new answer.

The history you can read differs from the recent memory AI uses to answer: loading older messages does not mean AI will recall them all. If AI cannot identify older content, restate the asset, period, and claim. Reading history alone does not create a new AI turn.

## Expected result

You can send a question, check response sources, follow up, and reopen a conversation. AI supports research; it does not guarantee predictions or execute trades.

## Troubleshooting

| Symptom                                                                    | Next action                                                                                                                                                                                                |
| -------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| The AI Assistant is missing or an action is unavailable                    | Check the workspace and on-screen message; see [Missing data or features](/en/docs/ug08).                                                                                                                  |
| Sending fails or a response reports failure                                | Keep your question, read the message, and check the current conversation before resending to see which messages were recorded. Do not treat an old answer as the successful result of the failed question. |
| An AI turn limit is reported                                               | Check **Usage limits**, usage, and the reset time. Repeatedly submitting does not resolve a quota restriction; see [Missing data or features](/en/docs/ug08) if you need help.                             |
| History or conversation content fails to load                              | Use **Retry** in the affected area when available. If history is empty, check search terms and the workspace before concluding that a conversation does not exist.                                         |
| The answer lacks sources, uses the wrong scope, or contains contradictions | Ask for the sources or scope, compare original articles when available, and note what remains unverified. Do not assume one follow-up will resolve missing data.                                           |

If you cannot resolve the issue, note the workspace, conversation, question, time, and relevant message. See [Missing data or features](/en/docs/ug08) for help.
