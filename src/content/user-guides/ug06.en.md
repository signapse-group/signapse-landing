## Goal

Choose the intended asset and timeframe, read price movements, and compare context annotations on the chart. Distinguish annotation times from event occurrence times, and recognize missing, stale, or failed data before drawing conclusions about the market.

## Before you start

You need access to Market charts and a workspace with tracked assets.

Price data and event annotations may be incomplete for some assets or time ranges.

## Steps

### 1. Choose an asset and timeframe

Open **Market charts** in the app navigation. Check the current workspace, open the **Watchlist asset** selector, and choose the intended asset symbol and name.

Choose **Timeframe** from the displayed options. For example, **1h** means one-hour candles, not that the whole chart shows only one hour. Wait for loading to finish and recheck the asset and timeframe after each change.

The price chart uses the browser’s time zone. When comparing times with a source article or another screen, check the time zone so you do not mistake the same instant for two different times.

### 2. Read price data

Read the time and price axes, then examine candles in the visible range. When inspecting a candle and its displayed values, distinguish:

| Value | Meaning |
| --- | --- |
| **Open** | The candle's opening price for the selected timeframe. |
| **High / Low** | The highest and lowest prices in the candle data. |
| **Close** | The candle's closing price; a forming candle may continue changing as new data arrives. |
| **Volume**, when available | Volume accompanying the candle data. A missing value does not mean volume is zero. |

Compare several candles before and after the time of interest rather than relying on one candle. Candle or event marker colors do not replace reading prices, times, and accompanying content.

To view another period, move or zoom the chart using its available interactions. If **Loading history...** appears, wait for loading to finish; if history loading fails, read the message before interpreting the missing part. Do not assume a gap means the price stayed unchanged.

### 3. Read context types and compare times

Open **Events** on the toolbar to view **Event settings** and enable the **Events** layer if it is off. Check the loading message, event marker count, or message that no events are available in the current range.

Select a marker to read its context type, time, title, summary, and evidence when available. A marker may group several annotations; check each relevant item. Distinguish two context types:

| Context type | How to read it |
| --- | --- |
| Event | The chart marker may use the impact interpretation's observation time; it is not necessarily the event occurrence time or a measured price reaction. Open the details to compare times. |
| Monthly summary | A summary of an asset's context for a completed month. Read the accompanying period and summary; do not treat it as a single event occurring exactly at the marker's position. |

Select the event title to read **Occurred at** and check sources using [Reading news, events and evidence](/en/docs/ug05).

Read the annotation and event times, then compare candles in the same time zone. Each candle covers its entire timeframe; marker placement does not show that every price move followed the event. Timing alone does not prove causation.

If accompanying interpretation or impact evaluation is available, distinguish it from actual prices on the chart. No event markers in the visible range do not establish that no relevant market news or events exist.

### 4. Check freshness and handle unavailable data

Read the live price status and **Updated** time when available. Loaded candles and the live price connection need to be checked separately.

| Symptom | Next action |
| --- | --- |
| **Connecting live price / Reconnecting** | Wait for the connection state to change. Do not assume the last visible price is newly updated merely because the chart remains visible. |
| **Live data is stale** or **Updated … (stale)** | Note the freshness limitation. Use **Refresh** or **Reload latest data** when available, then recheck the state. |
| **Market closed** | Read it alongside the update time; do not infer an error from the absence of new prices on this state alone. |
| **No candle data for the selected asset** | Check the asset, timeframe, and reported **From / To** range. Reload when available; do not interpret empty data as an unchanged price. |
| **Live data error** or a chart loading error | Read the message and use the displayed retry or reload action. If the error persists, follow the support guidance below. |
| Candles are present but event annotations fail to load | Note that the event layer could not be read; available price data does not establish that event coverage is complete. |

## Expected result

You have selected the asset and candle timeframe, checked the displayed time zone, and can compare available prices and context.

## Troubleshooting

- **No selectable asset or a link opens the wrong asset:** check the workspace and watchlist. The linked asset may no longer belong to the current watchlist; select an appropriate asset using [Workspaces and watchlists](/en/docs/ug03).
- **The chart or event details cannot be opened:** Read the on-screen message and see [Missing data or features](/en/docs/ug08).
- **Data remains missing, stale, or in error:** note the asset, workspace, timeframe, time zone, visible range, time checked, and message. See [Missing data or features](/en/docs/ug08) for help.
