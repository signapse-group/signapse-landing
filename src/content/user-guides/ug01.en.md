## Goal

Sign in to Signapse, choose a workspace and the assets you want to follow, open market information, and check its supporting sources.

## Prerequisites and permissions

This guide is for people who have already been granted access to Signapse. Use the account that has been granted access to sign in and follow the steps below.

Individual actions still depend on your account permissions: choosing a workspace, creating one if needed, managing tracked assets, and reading events and articles. To complete the source-checking steps, the current data must include an event with evidence and a source article link. See [Account, permissions and limits](/en/docs/ug02) if you encounter a restriction.

## Steps

### 1. Sign in

Open the Signapse app address supplied by the person who granted access, then sign in with the account that has been granted access. If you do not have the address or cannot open it, contact that person to confirm where to sign in.

### 2. Choose or create a workspace

Open the workspace selector and choose the workspace you want to use. If you do not have a workspace and have permission to create one, select **Create workspace**, enter a name, and confirm with **Create workspace**.

After creating it, check the selector and select the new workspace if it is not already selected. Before continuing, make sure the displayed name matches the workspace you want to use.

### 3. Add assets to your watchlist

In the workspace selector menu, select **Manage tracked assets**. Search by asset name or symbol, check the name and asset type in the results, and select the asset you want to follow. Keep existing selections if you still want to follow those assets.

Select **Save list** and check for a successful update message. If the list already includes an asset you want to follow, you can continue without making changes.

See [Workspaces and watchlists](/en/docs/ug03) for the full management guide.

### 4. Open an event

Open **Events** in the app navigation. Select an event title to open its detail page, then read its description and **Occurred at** time. Check **Related assets**, when available, to determine whether the event relates to an asset you want to follow.

### 5. Check the evidence

On the event detail page, find **Evidence**. Read the article title, news outlet, publication time, and evidence note when available. Compare these with the event description to understand which sources support it.

Evidence or a confidence score does not mean every interpretation is certainly correct. If this section shows **No evidence yet**, you cannot check the event's supporting sources through this flow yet.

### 6. Read the source article

For the evidence you want to check, select **View article**, when available, to read the article in Signapse. Select **Open original link** on the article, or directly on the evidence when available, to open the external source in a new tab.

Compare the source article's title, news outlet, publication time, and content with the event information. Distinguish what the source actually states from Signapse's interpretation, and note when a source cannot be accessed or checked.

See [Reading news, events and evidence](/en/docs/ug05) for more detail.

## Expected result

You are using the intended workspace and watchlist, have opened an event, identified its supporting evidence, and read the source article when you have permission and an accessible link. You know which information you could check and which still lacks supporting evidence.

## Troubleshooting

- **An action is missing or unavailable:** check [Account, permissions and limits](/en/docs/ug02). Access to the app does not grant permission for every action. If a permission restriction still blocks you, contact the person who granted you access to check your account permissions.
- **Your tracked asset list was not saved successfully:** check the on-screen message and current list before trying to save again. See [Workspaces and watchlists](/en/docs/ug03).
- **Events, evidence, or source article links are missing:** see [Missing data or features](/en/docs/ug08). If an event search returns no results, review your search terms and active filters; do not conclude that there are no market events or that an event has been verified.
- **The source article will not open:** note that you could not check the source. Links outside Signapse may be inaccessible; the remaining information does not replace checking the source.
