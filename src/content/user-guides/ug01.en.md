## Goal

Sign in to Signapse, choose a workspace and the assets you want to follow, open market information, and check its supporting sources.

## Before you start

You have a Signapse account, sign-in details, and access to the app.

## Steps

### 1. Sign in

Open the Signapse app address supplied with your account and sign in. If you do not have the address or cannot open it, see [Missing data or features](/en/docs/ug08).

### 2. Choose or create a workspace

Open the workspace selector and choose the workspace you want to use. If you do not have a workspace, select **Create workspace**, enter a name, and confirm with **Create workspace**.

Check the workspace name in the selector; select the new workspace if needed.

### 3. Add assets to your watchlist

On **Overview**, select **Manage tracked assets** in the active workspace section. Search by asset name or symbol, check the name and asset type in the results, and select the asset you want to follow. Keep existing selections if you still want to follow those assets.

Select **Save list** and check for a successful update message. If the list already includes an asset you want to follow, you can continue without making changes.

See [Workspaces and watchlists](/en/docs/ug03) for the full management guide.

### 4. Open an event

Open **Events** in the app navigation. Select an event title to open its detail page, then read its description and **Occurred at** time. Check **Related assets**, when available, to determine whether the event relates to an asset you want to follow.

### 5. Check the evidence

In the event details, open **Evidence** and choose an article with a source link. Read its title, source, and publication time. If **No evidence yet** appears, choose another event or see UG08 below.

### 6. Read the source article

For the evidence you want to check, select **View article**, when available, to read the article in Signapse. Select **Open original link** on the article, or directly on the evidence when available, to open the external source in a new tab.

Compare the source article's title, news outlet, publication time, and content with the event information. Distinguish what the source actually states from Signapse's interpretation, and note when a source cannot be accessed or checked.

See [Reading news, events and evidence](/en/docs/ug05) for more detail.

## Expected result

You have selected a workspace, saved tracked assets, and opened an event’s source.

## Troubleshooting

- **An action is missing or unavailable:** Read the on-screen message and see [Missing data or features](/en/docs/ug08).
- **Your tracked asset list was not saved successfully:** check the on-screen message and current list before trying to save again. See [Workspaces and watchlists](/en/docs/ug03).
- **Events, evidence, or source article links are missing:** see [Missing data or features](/en/docs/ug08). If an event search returns no results, review your search terms and active filters; do not conclude that there are no market events or that an event has been verified.
- **The source article will not open:** note that you could not check the source. Links outside Signapse may be inaccessible; the remaining information does not replace checking the source.
